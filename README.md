# 2D Arcade Game

ინტერაქტიული 2D არკადული თამაში და PixiJS v8 სადემონსტრაციო ლაბორატორია (React + TypeScript + Tailwind CSS + Pixi.js).

## 🚀 ლოკალურად გაშვების ინსტრუქცია (Local Setup)

### წინაპირობები (Prerequisites)

- **Node.js**: ვერსია 18 ან უფრო ახალი (რეკომენდებულია LTS 20+)
- **npm** (ან **bun** / **pnpm** / **yarn**)

---

### ნაბიჯი 1: პროექტის საქაღალდეში შესვლა

გახსენით ტერმინალი (Terminal / Command Prompt / PowerShell) პროექტის მთავარ საქაღალდეში:

```bash
cd <პროექტის_საქაღალდე>
```

### ნაბიჯი 2: Install Dependencies

გაუშვით ერთ-ერთი შემდეგი ბრძანება:

**npm-ის გამოყენებით:**

```bash
npm install
```

_(თუ ძველი npm-ის გამო წააწყდებით peer dependencies-ის შეტყობინებას: `npm install --legacy-peer-deps`)_

_(ან თუ იყენებთ Bun-ს: `bun install`)_

---

### ნაბიჯი 3: დეველოპმენტ სერვერის გაშვება (Start Dev Server)

```bash
npm run dev
```

გაშვების შემდეგ გახსენით ბრაუზერში:
👉 **http://localhost:3000**
